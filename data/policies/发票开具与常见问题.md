# 拾汇商城发票开具与常见问题

## 一、可开具的发票类型

1. **电子普通发票**（默认类型）：下单时选择"普通发票（电子）"，订单完成后系统自动开具，可在订单详情或发票管理中下载 PDF；其法律效力与用途同纸质普通发票，可用于报销与保修凭证，**下载不限次数**。按税务规定，**手机号为必填项**，邮箱为选填项。
2. **全面数字化的电子发票（数电票）**：平台优先开具数电票。数电票与纸质发票法律效力、基本用途相同，不影响报销；票面由"发票代码 + 发票号码"变为 **20 位发票号码**，取消密码区、发票代码、校验区、收款人、复核人及销售方章，**无联次、无需邮寄**，订单完成后即可在发票详情页预览下载或发送至邮箱。自行打印纸质件作为税收凭证**无需加盖发票专用章，但必须同时保存 XML 数据电文**；平台暂不支持 OFD 格式，自营订单可提供 XML 及 PDF。
3. **纸质普通发票或换开纸质专用发票**：用户自主换开纸质专用发票的，**邮寄服务费由用户承担**，可合并同一地址的订单一同支付，付款后预计 **1-3 日**内寄出。
4. **增值税专用发票**：下单时选择"增值税发票"自助申请，首次须先提交开票资质（路径：我的拾汇商城 → 账户设置 → 增票资质）。**一个账号只能关联 1 个开票资质，审核通过 30 天后方可删除**；**发票内容只能开具明细**；一般在订单完成后 **3-5 个工作日**内开具并寄出，寄出后可在订单详情查看邮寄单号。
5. **开票资质六项信息**：单位全称、统一社会信用代码（一般为 18 位）、注册地址、电话、开户银行、银行账号。信息填写错误导致无法认证抵扣的，平台不受理重开。

## 二、开票时间与操作方式

1. **电子普通发票**：订单完成后 **24 小时**内自动开具；每月 **1-6 日**因税务系统原因延长至 **48 小时**内开具。
2. **货到付款订单**：需确认收货、付款完成并经财务对账后开具；在线支付订单在确认收货、订单完成后开具。
3. **企业集中开票**（自营多单合并开具）：电子普通发票 **1-2 个工作日**、增值税专用发票 **3-5 个工作日**开出。
4. 下单时未选择开票的，可在订单完成后于"我的订单 → 发票管理"中申请补开。
5. **发票抬头**可选个人或公司；**发票内容**可选商品明细或商品类别，建议选择明细以便保修。数码、手机及配件、笔记本、台式机、家电类商品**无论是否索票均随单开具**，默认商品全称，可在提交订单时修改。

## 三、开票金额与开票范围

1. 发票金额为订单的**实付金额**，**不高于订单实际支付金额**。
2. **不予开票的部分**：优惠券（含平台券、店铺券）、拾汇积分、礼品卡等抵扣或支付的金额**不开具发票**；**账户余额支付的部分可以开票**。
3. 因商品故障等原因以平台余额进行补偿或赔偿的，电子发票开具金额 = 原订单实付金额 − 余额补偿金额。
4. **一张订单对应一张电子普通发票**；系统自动拆分订单时，每个子订单各开具一张发票；**不同物流中心开具的发票无法合并**。
5. 单张发票金额上限为 **10 万元**，超过部分需分单开具。
6. **不得开具增值税专用发票的情形**：商业企业一般纳税人零售的烟、酒、食品、服装、鞋帽（不含劳保专用部分）、化妆品等；部分生鲜商品；参与超级补贴等活动的商品不支持公司抬头增票，但可开具公司抬头的普通发票。

## 四、发票修改、换开与重开

1. **订单完成前**可在"我的订单 → 修改发票"中修改：电子发票可增补税号、抬头由个人改公司或公司改个人、内容在明细与类别之间互换、电子发票改为增值税专用发票，增票也可改为电子发票。
2. **订单完成后**，开票后 **90 个自然日**内可申请重开（需作废原发票，纸质发票需配合退回原件）；订单完成后 **2 年内**仍可在"我的拾汇商城 → 客户服务 → 我的发票"中修改部分开票信息，如增补税号、地址电话、开户行及账号。
3. **电子发票一旦提交开具申请即无法修改**（系统将自动发送）。
4. **第三方商家商品**：发票内容的修改须在**订单完成前**申请；换开须在订单状态显示"完成"后**一年内**申请，逾期入口关闭，需与商家协商。
5. 数电票不支持换开为电子发票及增值税专用发票；已被勾选入账或抵扣的，须先取消勾选或完成"红字发票信息确认单"确认，**红字确认单超过 72 小时未确认即作废**。
6. 超过 90 天且无法通过自助渠道重开的，请联系人工客服协助处理。

## 五、发票与退货、价保的关系

1. 选择电子普通发票的用户办理退换货**无需退回发票**，平台按冲红处理（原发票显示无效）；换新或退货后重新购买的会重新开具发票，原发票作废。
2. 订单申请退货时，平台按发票管理办法开具红字发票，并对未发生退货的商品重新开具；若发票已被勾选抵扣或入账，需用户配合取消勾选或完成红字确认单。
3. **电子普通发票在订单退货后作废，无法再次下载**。
4. **第三方商家商品**：商家已提供发票而最终退货退款的，需将发票一并退回；未退回的需与商家协商，**可能需要按实际情况向商家支付相应发票税款**。
5. 使用拾汇礼品卡支付的商品，因礼品卡支付部分不开具金额发票，如需发票用于保修，可申请开具**零元保修电子发票**。
6. 已开具增值税专用发票或数电发票已报销、抵扣的订单，价格保护的差额以**拾汇积分**形式返还。

## 六、未收到发票怎么办

1. **电子发票**：优先在"我的订单 → 发票管理"中自行下载或重新下载，并检查手机短信、邮箱或发票夹是否已收到。
2. **自营商品**：电子发票未开具的可联系平台客服申请开具；全额使用礼品卡、优惠券支付而无发票的，可联系客服开具 **0.01 元保修发票**。
3. **第三方商家商品**：开票时限为下单时申请，或订单状态显示"完成"后 **90 天内**申请；逾期"申请开票"入口关闭，需与商家协商补开。
4. **少开发票、错开发票、拒开发票**：可先向商家申请补开或换开；商家已审核或超时未审核后 **15 天内**，可发起"发票问题"类型的交易纠纷申请平台介入。
5. 申请平台介入时，需提供申请开票的系统截图或聊天截图、纸质发票高清照片或电子发票 PDF；商家可反举证。卖家拒绝补开的，可提交第三方卖家交易纠纷。
6. 存在不可抗力、交易事实无法查清、双方已协商履行完毕又反悔、虚假交易或卡券套利等情形的，平台有权不予受理。
7. 发票相关问题（开票内容、金额、类型、重开时限）均可通过客服渠道咨询，人工客服会核实订单与开票记录后处理。

## 七、发票常见问题速查

**Q：优惠券、积分抵扣的金额可以开进发票里吗？**
不可以。发票按实付金额开具，优惠券、积分与礼品卡抵扣部分的金额不开具发票；账户余额支付的部分可以开票。

**Q：能用别人的抬头开票吗？**
可以按实际购买方要求填写抬头，但抬头与税号须真实准确；开票后 90 天内填写有误的可申请重开。

**Q：退货后发票怎么处理？**
电子普通发票无需退回，平台按冲红处理，退货后原电子发票作废且无法再次下载；第三方商家已提供的发票需一并退回，未退回的可能需承担相应发票税款。

**Q：开票后商品降价并申请了价保，发票会变吗？**
尚未开票或为电子发票的，发票金额会按退款后的支付金额变化；已开具增值税专用发票或数电发票已报销、抵扣的，差额以拾汇积分形式返还。

**Q：忘记选开票，事后还能补开吗？**
可以。在订单完成后进入"我的订单 → 发票管理"申请补开电子普通发票；需要专票的，补充完整开票资质信息后由平台审核开具。

**Q：为什么这张商品开不了增值税专用发票？**
烟、酒、食品、服装、鞋帽（不含劳保专用部分）、化妆品等零售商品，以及部分生鲜商品、参与超级补贴等活动的商品按规定不支持开具增值税专用发票，可开具公司抬头的普通发票。
