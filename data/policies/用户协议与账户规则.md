2. 用户确认全部服务条款并完成注册程序时，本协议即告成立并生效，用户同时成为拾汇商城正式用户。
3. 《拾汇商城隐私政策》、平台规则、单独协议均为本协议的补充协议，与本协议不可分割且具有同等法律效力；使用平台服务即视为同意上述补充协议。

## 二、账户注册与实名认证

1. **用户资格**：注册前用户应具备与自身行为相适应的民事行为能力；不具备的，需在监护人监护参与下使用，用户及监护人依法承担因此产生的后果。
2. **注册要求**：按注册页面提示填写信息、阅读并同意本协议并完成全部注册程序后，用户获得拾汇商城账户。
3. **账户名规范**：账号名、昵称、头像不得违反法律法规及平台规则，未经他人许可不得以他人名义（冒用姓名、名称、字号、头像等）开设账号，不得恶意注册。违规时平台有权拒绝设置或收回账号名、昵称。
4. **一人一号**：平台原则上只允许每位用户使用一个账户。存在不当注册或不当使用多个账户情形的，平台可采取冻结或关闭账户、取消订单、拒绝提供服务等措施；造成损失的，用户应承担赔偿责任。
5. **信息真实性**：用户应按页面提示准确、完整提供姓名、电子邮箱、联系电话、联系地址等信息，并保持其真实、有效；信息变更应及时更新。
6. **实名认证**：为保障账户安全，平台可要求用户按相关法律法规规定完成实名认证。认证路径为"我的拾汇商城 → 账户设置 → 账户安全 → 实名认证"，按页面提示操作。
   - 使用拾汇积分抵扣订单金额、开通积分支付等功能**必须以完成实名认证为前提**。
   - 个人账号无法升级为企业账号，企业采购需求需直接注册企业会员账号。
7. **信息核实**：平台依法可对用户信息进行核查。如按最后一次提供的信息联系未果、用户未及时提供信息、信息明显不实或经行政司法机关核实无效，用户承担由此造成的损失；平台可要求整改或重新认证，直至中止、终止提供部分或全部服务。

## 三、账户使用与账户安全

1. 账户关联用户的个人信息与平台商业信息，**仅限用户本人使用**，用户应对账户下的所有行为结果负责，不得以任何方式转让账户；直接或间接授权第三方使用账户的后果由用户自行承担。
2. 账户由用户自行设置并保管，**拾汇商城任何时候均不会主动要求用户提供账户密码**。建议用户在每个上网时段结束时退出登录，并以正确步骤离开平台。
3. 因用户主动泄露，或账户遭受他人攻击、诈骗等行为导致的损失及后果，平台不承担责任，用户应通过司法、行政等途径向侵权人追偿。
4. 发现账户未经授权被登录或可能遭窃、遗失的，建议立即通知平台；平台对用户请求采取行动需要合理时间，除平台存在法定过错外，不承担责任。
5. **账户安全设置**：平台提供邮箱验证、手机验证、支付密码、数字证书、实名认证等安全项，设置项越完整账户安全等级越高。修改登录密码可通过电脑端"我的拾汇商城 → 设置 → 账户安全 → 修改登录密码"或 App 端"我的 → 账户管理 → 账户与安全"完成；收到账号异常或风险提示时，应按提示重置密码并定期修改密码。
6. **长期未登录（沉默账户）**：
   - 连续 **3 个月** 未登录的，平台有权**暂时解除**账户与手机号的绑定关系；
   - 连续 **12 个月** 未登录，且账户内无未到期的优惠券、拾汇积分、礼品卡等资产，也不存在未到期的有效业务的，视为用户自愿放弃，平台有权收回该账户的使用权；账号下的个性化设置（头像、昵称等）将无法恢复。收回前平台会以适当方式做出提示。

## 四、账户注销

1. 用户仅能申请注销本人的账号，并应依照《拾汇商城账号注销须知》办理。注销入口：电脑端"账号注销"（可注销拾汇商城旗下关联账号），App 端"我的 → 账户设置 → 账户安全 → 注销账号"。
2. 用户仍应对注销前使用账号服务期间的行为承担责任。
3. **前置条件**：账号如同时绑定平台商家店铺，须先解除绑定；注销期间如涉及投诉、举报、诉讼、仲裁或国家机关调查，平台有权自行终止注销流程。
4. **不予注销的情形**：账号存在开店记录、投诉举报记录、被限制记录、欠款，或开通了拾汇商城以外的其他平台业务等。
5. **注销影响**：
   - 账号注销后**不可恢复**；前台个人信息将被去除或匿名化，但**交易记录须在后台依法保存 5 年甚至更长时间**；
   - 账户内的余额、优惠券、拾汇积分、礼品卡、各类资格、订单权益等**视为用户自行放弃**，无法找回；
   - 申请注销账户视为放弃账户信息及该账户在平台的资产、虚拟权益等，平台无法恢复前述服务，可能对用户主张售后服务带来不便。

## 五、购物与下单基本规则

1. 购买商品或服务时应仔细确认名称、价格、数量、型号、规格、尺寸、联系地址、电话、收货人等信息；收货人与用户本人不一致的，收货人的行为和意思表示视为用户的行为和意思表示，**用户对收货人行为的法律后果承担连带责任**。
2. 购买行为应为生活消费需要，不得恶意购买、恶意维权或扰乱平台正常交易秩序；平台发现上述情形可采取暂停或停止服务、取消订单等必要管控措施，并作出账户处置。
3. **合同成立时点**：平台上展示的商品和价格信息仅为要约邀请；用户下单填写内容生成的订单信息为向销售商发出的合同要约；销售商将订单商品实际出库发货时，双方就实际发出的商品成立合同关系。电子书、数字音乐、在线充值、机票、旅游产品等非实物商品，用户下单并支付货款后合同即成立。
4. **缺货与标错价**：因市场变化等难以控制因素出现缺货、价格标示错误时，用户有权取消订单，销售商亦有权自行取消订单；用户已付款的，为其办理退款并提供订单处理方案。

## 六、评价与晒单规则

1. 用户有权在评价系统中对已达成交易的商品或服务进行评价，评价信息为公开信息；为向用户提供更好的购物信息与交流需求，平台有权以任何形式使用评价内容。
2. 评价内容应合法、客观、真实，与交易的商品或服务具有关联性，不得包含污言秽语、色情低俗、广告信息及法律法规禁止的其他信息。
3. 不得以不正当方式帮助他人提升信用，或利用评价权利对其他用户实施威胁、敲诈勒索；平台可对违规评价采取必要处置措施。

## 七、配送与交付（概要）

1. 商品按用户指定的送货地址配送；订单信息中列出的送货时间为参考时间，根据库存状况、正常处理过程和送货地点估算。
2. 用户变更联系人或配送信息造成的损失由用户自行承担。
3. 因客户提供错误信息或地址不详、货物送达无人签收或拒收、不可抗力（自然灾害、恶劣天气、交通戒严、政府或司法机关行为、意外交通事故、罢工、法规政策修改、暴力犯罪、战争等）导致订单延迟或无法配送的，平台不承担迟延或无法配送的责任。
4. **交付时间**：由关联方或第三方配送公司完成交付的，系统或单据记录的签收时间为交付时间；采用在线传输方式交付的，销售商向用户指定系统发送的时间为交付时间；购买服务的，生成的电子或实物凭证或订单载明的时间为交付时间。
5. 配送范围、时效、运费与异常处理详见《拾汇商城配送与运费政策》。
